Motivation

Figure 1. Binary success-rate evaluation can hide important execution differences. Two rollouts may both succeed while differing substantially in motion smoothness, retries, collisions, and efficiency. Eval-Actions adds supervision for task success, fine-grained quality, and trajectory source, while AutoEval learns to predict these diagnostic signals from manipulation videos and compact robot-state summaries.

Abstract

Although Vision-Action (VA) and Vision-Language-Action (VLA) policies have substantially improved robotic manipulation capabilities, existing evaluation protocols relying only on binary success rates fail to capture fine-grained execution differences, such as motion smoothness, anomalous collisions, and execution efficiency. We redefine robotic manipulation evaluation as a fine-grained video Action Quality Assessment (AQA) problem and introduce Eval-Actions, a diagnostic benchmark integrating RGB-D videos and robot-state trajectories from both policy-generated and human-teleoperated executions. Eval-Actions provides three complementary supervision signals: criteria-based Expert Grading (EG), metric-calibrated Rank-Guided (RG) labels, and Chain-of-Thought (CoT) diagnostic annotations. Built on this benchmark, AutoEval jointly processes visual temporal evidence and compact kinematic summaries. AutoEval-S uses Spatio-Temporal Aggregation to preserve short-term motion cues within a strict VLM token budget, while AutoEval-P uses Group Relative Policy Optimization (GRPO) to improve CoT-style diagnostic reasoning.

Benchmark Overview

Figure 2. Eval-Actions covers diverse robotic manipulation scenarios, including single-arm interactions and complex bimanual coordination. Each episode contains synchronized sensory and trajectory information, including RGB-D recordings, 7/14-DoF robot-state trajectories, action trajectories, task descriptions, success labels, trajectory source labels, and diagnostic quality annotations. The benchmark intentionally includes smooth successes, low-quality successes, partial failures, and complete failures to support evaluation beyond binary task completion.

Dataset Comparison

Table 1. Compared with training-centric robotic manipulation datasets, Eval-Actions is designed for diagnostic evaluation. It contains failure cases, mixed trajectory sources, fine-grained quality scores, and CoT-style explanatory annotations based on RGB-D videos and robot trajectories.

Eval-Actions Annotations

Expert Grading (EG)

Experts score each execution on a 1-10 scale using criteria including task completion, motion smoothness, visible collision-related events, and execution efficiency.

Rank-Guided Labels (RG)

Measurable motion indicators are calibrated with expert rankings to produce metric-grounded quality labels without leaking validation or test information.

CoT Diagnostics

Textual annotations explain observable evidence such as retries, abrupt motion, object drops, abnormal contacts, efficiency, final score, success, and trajectory source.

AutoEval Framework

Figure 5. AutoEval processes manipulation videos and kinematic prompts. AutoEval-S uses Spatio-Temporal Aggregation for structured score, success, and source prediction, while AutoEval-P uses GRPO to improve CoT-style diagnostic reasoning.

Video + Kinematics

AutoEval takes RGB temporal evidence and compact robot-state summaries, using motion statistics as calibration signals for smoothness and efficiency.

AutoEval-S

Spatio-Temporal Aggregation stitches short frame windows into composite visual inputs, preserving dense motion cues while keeping the VLM token budget fixed.

AutoEval-P

GRPO optimizes CoT-style outputs with rewards for score accuracy, success prediction, source prediction, and output format consistency.
